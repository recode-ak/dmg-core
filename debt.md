# Технический долг пакета `dmg-core`

Осознанные отступления от правил и решений пакета. Каждая запись — маркер `// DEBT-<n>: …` в коде (`src/`, `scripts/`) и наоборот; соответствие проверяет `scripts/debt-check.test.ts` (в `bun run check`). Файл в tarball не входит: это реестр разработки пакета, а не документация потребителя.

Формат записи: **Место**, **Причина**, **Погашает**, **Критерий снятия**. Погашенный долг удаляется вместе с маркером.

### DEBT-1: повтор команды не отсеивается по `requestId`
- **Место:** `src/app/module/module-from-def.ts` (`dispatch`)
- **Причина:** правило D-49 / [`transport.md`](./docs/transport.md) §2: `requestId` — одно намерение клиента, повтор command UC с тем же `requestId` от того же caller не исполняется дважды (сохранённый ответ; другой вход — конфликт; серверный `requestId` и query — без отсева). In-proc повторов нет, поэтому `dispatch` `meta` пока не исполняет; нужны хранилище ответов с TTL и код ошибки конфликта.
- **Погашает:** HTTP-адаптер транспорта (первый транспорт с повторной доставкой)
- **Критерий снятия:** `dispatch` (или адаптер транспорта) отсеивает повтор по правилу `transport.md` §2, тесты повтора и конфликта, маркер удалён
- **История:** до выноса пакета — DEBT-36 в реестре u7-school
