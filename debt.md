# Технический долг пакета `dmg-core`

**Назначение:** осознанные отступления от правил и решений пакета. Файл в tarball не входит: это реестр разработки пакета, а не документация потребителя.

**Последний выданный ID:** DEBT-1

Реестр — allowlist (D-84): код к записи привязывают её поля, а не маркеры в коде. Сверку выполняет `DebtChecker` из `dmg-core/arch` (ARC-12) в тесте `src/arch/debt-checker.test.ts` (в `bun run check`). Новый ID — следующий после «Последнего выданного», строка правится тем же коммитом; номера не переиспользуются, закрытая запись удаляется.

```
### DEBT-<n>: <краткое название>
- **Место:** `<glob>`, `<glob>` — <пояснение>
- **Признак:** `<регулярка, флаг m>`
- **Корень:** `<glob>` — где признак вне Места — долг без записи (нет поля — весь код)
- **Причина:** <почему нельзя убрать сейчас>
- **Погашает:** <трек>            ← или **Триггер:** <условие>
- **Критерий снятия:** <что должно исчезнуть>
```

ID в коде — только в строке `biome-ignore`. Проверяемый код — `src/` и `scripts/` без тестов; маркеры временности («Временное решение», «Уходит с миграцией», «ВРЕМЕННЫЙ») допустимы только в Месте записи (кроме `scripts/` и самого `DebtChecker`).
