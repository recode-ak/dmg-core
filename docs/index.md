# Документация `dmg-core`

**Назначение:** оглавление `docs/`: к какому разделу идти по задаче. Вход для агента и человека — [llms.txt](../llms.txt); образец во всех документах — учебный модуль пакета ([src/testing/example](../src/testing/example/example.arch.ts)).

---

- [Справочник](./reference/index.md) — нужно знать, что обязательно: правила, имена, контракты, стиль
- [Гайды](./guides/index.md) — пишешь артефакт, начинаешь проект, выносишь модуль, расширяешь граф или `gen` поставщиком
- [Решения](./decisions.md) — нужна причина конкретного решения по его ID; запись читает `dmg-core docs show`
- [Процесс](./process.md) — планируешь работу: постановка, роли, срез, проверки
- [Как устроена документация](./writing-docs.md) — правишь документы пакета: что куда писать, кто и когда актуализирует
- [Как устроено и почему](./concepts/index.md) — хочешь понять поток или устройство: путь вызова, жизненный цикл, слои
